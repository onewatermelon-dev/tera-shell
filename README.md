# Tauri + Vue + TypeScript

该模板应该可以帮助您开始在 Vite 中使用 Vue 3 和 TypeScript 进行开发。模板使用Vue 3`<script setup>`证监会，请查看[脚本设置文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup)了解更多。
